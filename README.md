# My First AWS Project: Static Website on S3

## Project Overview
This is my first cloud project where I deployed a personal website using **Amazon S3**.  
It demonstrates basic **cloud hosting skills**, **bucket configuration**, and **public access policies**.

## Features
- Static website hosted on **AWS S3**
- Live on the internet with a **public URL**
- Clean and responsive **HTML + CSS UI**
- Sections include:
  - About Me
  - Projects
  - Contact

## Technologies Used
- **AWS S3**: For hosting static files
- **HTML / CSS**: Frontend design
- **AWS Console**: Used to configure bucket policies and enable static website hosting

## Learning Outcomes
- Learned to create and configure **S3 buckets**  
- Enabled **public access** using **bucket policies**  
- Hosted a live website without using servers (serverless)  
- Understood AWS Free Tier usage and cost management

## Live Project
Visit my live website here -> http://prasad-first-demo.s3-website-us-east-1.amazonaws.com
